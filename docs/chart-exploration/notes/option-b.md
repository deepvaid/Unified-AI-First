# Option 2 · Multi Colour (`?chart=optionB`)

**Philosophy**: a fixed categorical order so the same channel keeps the same
colour on every chart.

Supplied family hexes were reordered to avoid green↔red / green↔orange CVD
collisions. Low-chroma teal and deep-blue slots were lifted into C ≥ 0.10.

| Slot | Role | Hex | Family |
|---|---|---|---|
| s1 | blue | `#1689C9` | supplied lead |
| s2 | orange | `#F28E2B` | supplied |
| s3 | teal | `#009B94` | chroma-lifted from `#76B7B2` |
| s4 | red | `#E15759` | supplied |
| s5 | deep blue | `#266099` | chroma-lifted from `#4E79A7` |
| s6 | green | `#59A14F` | supplied |

Yellow `#EDC948` was dropped (off-band). Purple sits out of the six-slot set
so red and green never neighbour it.

Axis (blue ramp): `#1E4E93` `#2E67B5` `#4A82CE` `#6C9DDF` `#8FB3E6`
