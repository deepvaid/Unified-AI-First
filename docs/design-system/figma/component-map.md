File: **Marobase Design System** — https://www.figma.com/design/RJJ0qDChSdh0FwH2UG0t7t (run `marobase-2026-09`).
Code Connect is unavailable on the Pro plan, so this table plus the variables' WEB code syntax are the contract.
Rows are added as each set is built; node ids come from `build-state.json`.

Prop vocabulary shared by both sides: `size sm|md|lg` · `emphasis default|prominent` · `variant` = structure ·
`density default|compact` · `tone` (surface: neutral|error · feedback: info|success|warning|error) ·
`state default|hover|focus|disabled (+ error / selected / active)`.

## Molecules (built — Phase 3b, 2026-09-07)

Every molecule composes the atoms above (Button, Icon Button, Field, Chip, Status Chip, Badge, Avatar, Menu Item, Nav Item, Tab, Segment, Divider, Kbd, Illustration, Icon). Slots are INSTANCE_SWAP properties (`Body content`, `Content`, `Control`, `Lead`); nested atoms are exposed instances so Label/State can be edited per child. Alpha values live in RGBA variables (`border/hairline` 12 %, `text/medium-emphasis` 60 %, `surface/tooltip` 90 %, `surface/skeleton` 8 %, `accent/border-soft` 22 %) or in layer opacity — never in paint opacity (not inherited by instances).
